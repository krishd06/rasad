# rasad

Tactical Command Centre Web Application built with React, Vite, Tailwind CSS, Supabase, Lucide Icons, Recharts, and Leaflet.

### Features
- Dark command-centre aesthetic (`bg-slate-950`, emerald accents)
- Multi-page navigation (Overview, What-If Simulation, Alerts, Reports, Copilot AI, Login)
- Telemetry analytics with Recharts & Geospatial node tracking with Leaflet
- Environment configuration secured via `.env.local`
